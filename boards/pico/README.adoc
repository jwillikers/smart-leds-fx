Examples of lighting effects for the {Raspberry-Pi-Pico}.

== Setup

. First, clone the repository.
+
[,sh]
----
git clone https://github.com/jwillikers/smart-leds-fx.git
----

. Change to the board's directory.
+
[,sh]
----
cd smart-leds-fx/boards/pico
----

. Load the development environment for the board.
{Nix} provides the toolchain and the tools to flash the board.
Refer to the link:../../README.adoc#develop[Develop section] of the project's README for instructions on setting up Nix and direnv.
With direnv, allow the environment to load automatically when entering the directory.
+
[,sh]
----
direnv allow
----
+
Alternatively, enter the environment with `nix develop`.
+
[,sh]
----
nix develop ../..#pico
----

== Pins

The examples refer to the pins of the Raspberry Pi Pico by name, such as `gpio7`.
These names are defined in link:src/lib.rs[src/lib.rs], which takes the place of the {rp-pico-crate} board support package.
The definitions are adapted from version 0.9.0 of that crate, so the pin names, the pin aliases, the boot loader for the W25Q080 flash chip, and the 12 MHz crystal frequency are all identical.
The board support package depends on rp2040-hal 0.10.
Defining the pins locally allows the examples to use the latest release of rp2040-hal.
In code, import the pins and other definitions from this crate instead of the board support package, as shown below.

[,rust]
----
use smart_leds_fx_pico::{entry, hal, pac, Pins, XOSC_CRYSTAL_FREQ};
----

Most pins are named after their GPIO number, which matches the GP number printed next to the header pin on the board.
The pins for the Pico's onboard functions have descriptive names instead.
Refer to the {Raspberry-Pi-Pico-Pinout} for the physical location of each pin.

[cols="1m,1,2"]
|===
|Name |GPIO |Function

|gpio0 - gpio22
|GPIO0 - GPIO22
|Header pins GP0 - GP22

|b_power_save
|GPIO23
|Controls the power save mode of the onboard voltage regulator

|vbus_detect
|GPIO24
|High when VBUS is present

|led
|GPIO25
|The onboard LED

|gpio26 - gpio28
|GPIO26 - GPIO28
|Header pins GP26 - GP28, which are also the analog inputs ADC0 - ADC2

|voltage_monitor
|GPIO29
|Measures VSYS / 3 with ADC3
|===

Each header pin also has type aliases for its functions, which follow the pattern `Gp<GPIO><Peripheral><Signal>`.
For example, `Gp7Spi0Tx` is GPIO7 configured as the TX pin of SPI0 and `Gp4I2C0Sda` is GPIO4 configured as the SDA pin of I2C0.

The examples use the following pins.

[cols="1m,2"]
|===
|Name |Use

|gpio4
|SPI0 RX, which is required by the SPI peripheral but not connected

|gpio6
|SPI0 SCK, which is required by the SPI peripheral but not connected

|gpio7
|SPI0 TX, which is the data line for the NeoPixels

|gpio28
|ADC2, which reads the {Phototransistor} in the `rgbw-neopixel-strand-marching-candy-cane` example
|===

== Program

The Raspberry Pi Pico can be programmed directly through its micro USB port or using its SWD pins.

=== UF2

{elf2uf2-rs} makes it incredibly easy to flash the Raspberry Pi Pico using its micro USB port.

. While holding the `BOOTSEL` button, attach the Raspberry Pi Pico to your computer using the micro USB port.

. Flash the board using the `nix run` command with the `pico-flash` app.
The name of the example can be given as an argument.
+
[,sh]
----
nix run ../..#pico-flash -- rgbw-neopixel-stick-soft-blink
----
+
Alternatively, use the `flash` recipe in the board's justfile.
+
[,sh]
----
just flash rgbw-neopixel-stick-soft-blink
----

=== SWD

Opposite the micro USB port on the Raspberry Pi Pico are three pins for making an SWD connection.
Support for the Raspberry Pi Pico is missing for many popular debug probe tools currently, so using a second Raspberry Pi Pico as the debug probe works best.
Refer to <<picoprobe>> for instructions.
This section describes the general instructions to use any debug probe.

. Flash and run an example with the `nix run` command and the `pico-run` app, which uses {probe-rs}.
+
[,sh]
----
nix run ../..#pico-run -- rgbw-neopixel-stick-soft-blink
----
+
Alternatively, use `cargo run`, which uses the {probe-rs} runner configured in link:.cargo/config.toml[.cargo/config.toml].
+
[,sh]
----
cargo run --example rgbw-neopixel-stick-soft-blink
----

==== picoprobe

The `picoprobe` is a Raspberry Pi Pico configured to run as a debug probe.
To use the `picoprobe` to flash and debug the examples, follow these instructions.

. Now, boot the Raspberry Pi Pico in bootloader mode by holding the `BOOTSEL` button while plugging it in.

. Download the {UF2} file containing the `picoprobe` firmware.

. Download and install the `picoprobe` firmware: https://github.com/majbthrd/DapperMime/releases/download/20210225/raspberry_pi_pico-DapperMime.uf2.
+
[,sh]
----
wget --relative --directory-prefix=/run/media/$USER/RPI-RP2/ https://github.com/majbthrd/DapperMime/releases/download/20210225/raspberry_pi_pico-DapperMime.uf2
----

. Wire the two Picos together according to the instructions https://datasheets.raspberrypi.org/pico/getting-started-with-pico.pdf#%5B%7B%22num%22%3A60%2C%22gen%22%3A0%7D%2C%7B%22name%22%3A%22XYZ%22%7D%2C115%2C841.89%2Cnull%5D[here].

== Examples

rgbw-neopixel-stick-soft-blink:: A _{soft-blink}_ effect for an {RGBW-NeoPixel-Stick} containing 8 RGBW {NeoPixel}s using the SPI MOSI pin, pin GPIO7, of the Raspberry Pi Pico.
rgbw-neopixel-strand-marching-candy-cane:: A candy cane pattern of alternating red and white stripes, each 9 LEDs long, for a strand of 743 RGBW {NeoPixel}s using the SPI MOSI pin, pin GPIO7, of the Raspberry Pi Pico.
The strand consists of {Adafruit-NeoPixel-Digital-RGBW-LED-Strip-White-PCB-30-LED} chained together.
At 30 LEDs per meter, 743 LEDs is just under 25 meters, or about five 5 meter strips.
The stripes march along the strand by swapping one LED in each quarter of the strand between red and white every 100 milliseconds.
An analog pin, GPIO28 (ADC2), is connected to a {Phototransistor} which is connected to ground via a 1 kΩ resistor.
This is used to turn the LED's off when in daylight.
The lights come on for the night at dusk and during dark cloudy weather.
A moving average is used to filter out noise.
