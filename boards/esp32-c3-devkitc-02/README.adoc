Examples of lighting effects for the {ESP32-C3-DevKitC-02}.

== Setup

. First, clone the repository.
+
[,sh]
----
git clone https://github.com/jwillikers/smart-leds-fx.git
----

. Change to the project's directory.
+
[,sh]
----
cd smart-leds-fx/boards/esp32-c3-devkitc-02
----

. Load the development environment for the board.
{Nix} provides the toolchain and the tools to flash the board.
Refer to the link:../../README.adoc#develop[Develop section] of the project's README for instructions on setting up Nix and direnv.
With direnv, allow the environment to load automatically when entering the directory.
+
[,sh]
----
direnv allow
----
+
Alternatively, enter the environment with `nix develop`.
+
[,sh]
----
nix develop ../..#esp32-c3-devkitc-02
----

. Attach the ESP32-C3-DevKitC-02 to your computer using the micro USB port.

. Build, flash, and monitor an example using {espflash} with the `nix run` command and the `esp32-c3-devkitc-02-flash` app.
The name of the example can be given as an argument.
+
[,sh]
----
nix run ../..#esp32-c3-devkitc-02-flash -- rgbw-neopixel-stick-high-low-soft-blink
----
+
Alternatively, use `cargo run`, which uses the espflash runner configured in link:.cargo/config.toml[.cargo/config.toml].
+
[,sh]
----
cargo run --release --example rgbw-neopixel-stick-high-low-soft-blink
----

== Examples

rgbw-neopixel-stick-high-low-soft-blink:: A _{soft-blink}_ effect for an {RGBW-NeoPixel-Stick} with 8 RGBW {NeoPixel}s using the SPI MOSI pin GPIO7 on the ESP32-C3-DevKitC-02.
Each LED alternates in color and the rise and fall of the soft blink effect.

rgbw-neopixel-strand-high-low-soft-blink:: A _{soft-blink}_ effect for an RGBW NeoPixel Strand with 240 RGBW {NeoPixel}s using the SPI MOSI pin GPIO7 on the ESP32-C3-DevKitC-02.
Each LED alternates in color and the rise and fall of the soft blink effect.

rgbw-neopixel-strand-white:: A simple example for setting an RGBW NeoPixel Strand with 240 RGBW {NeoPixel}s using the SPI MOSI pin GPIO7 on the ESP32-C3-DevKitC-02.
Each LED alternates in color and the rise and fall of the soft blink effect.
