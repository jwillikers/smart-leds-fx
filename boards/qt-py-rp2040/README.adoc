== Setup

. First, clone the repository.
+
[,sh]
----
git clone https://github.com/jwillikers/smart-leds-fx.git
----

. Change to the board's directory.
+
[,sh]
----
cd smart-leds-fx/boards/qt-py-rp2040
----

. Load the development environment for the board.
{Nix} provides the toolchain and the tools to flash the board.
Refer to the link:../../README.adoc#develop[Develop section] of the project's README for instructions on setting up Nix and direnv.
With direnv, allow the environment to load automatically when entering the directory.
+
[,sh]
----
direnv allow
----
+
Alternatively, enter the environment with `nix develop`.
+
[,sh]
----
nix develop ../..#qt-py-rp2040
----

== Pins

The examples refer to the pins of the QT Py RP2040 by the names printed on the board, such as `a3`.
These names are defined in link:src/lib.rs[src/lib.rs], which takes the place of the {adafruit-qt-py-rp2040-crate} board support package.
The definitions are adapted from version 0.8.0 of that crate, so the pin names, the boot loader for the GD25Q64CS flash chip, and the 12 MHz crystal frequency are all identical.

The board support package depends on rp2040-hal 0.10.
The newest release of {ws2812-pio}, 0.9, requires rp2040-hal 0.11 and is the first release that supports smart-leds 0.4.
Defining the pins locally allows the examples to use rp2040-hal 0.11 and the latest releases of ws2812-pio and smart-leds while keeping the same pin names.
In code, import the pins and other definitions from this crate instead of the board support package, as shown below.

[,rust]
----
use smart_leds_fx_qt_py_rp2040::{entry, hal, pac, Pins, XOSC_CRYSTAL_FREQ};
----

== Program

The Adafruit QT Py RP2040 can be programmed directly through its micro USB port.
{elf2uf2-rs} makes it incredibly easy to flash the Adafruit QT Py RP2040 using its micro USB port.

. While holding the `BOOTSEL` button, attach the Adafruit QT Py RP2040 to your computer using the micro USB port.

. Flash the board using Cargo's `run` subcommand.
+
[,sh]
----
cargo run --example rgb-neopixel-strand-high-low-soft-blink
----

== Examples

rgb-neopixel-strand-high-low-soft-blink:: A _{soft-blink}_ effect for an {Adafruit-NeoPixel-LED-Strip-with-3-pin-JST-PH-Connector} containing 30 RGB {NeoPixel}s.
The data line of the strip connects to the `A3` pin, GPIO26, of the Adafruit QT Py RP2040, which is driven by the PIO0 peripheral using {ws2812-pio}.
